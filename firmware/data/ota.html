Как собрать прошивку

Arduino IDE:
1. Открыть проект PC_Monitor.ino.
2. Установить плату: Tools → Board → ESP32 Dev Module.
3. Sketch → Export Compiled Binary.
4. Файл .bin появится в папке проекта.

PlatformIO:
1. pio run — сборка.
2. Файл: .pio/build/esp32dev/firmware.bin.

Загрузка:
1. Выбрать .bin файл выше.
2. Нажать «ЗАГРУЗИТЬ ПРОШИВКУ».
3. Дождаться 100% — ESP перезагрузится автоматически.

Размер: прошивка должна быть меньше свободного места на flash (обычно ~1.5 MB для ESP32 с OTA). Если больше — выбери раздел побольше в Arduino IDE: Tools → Partition Scheme → Minimal SPIFFS (Large APP).
