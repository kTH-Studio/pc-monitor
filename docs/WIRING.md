# Схема подключения

## ESP32 DevKit — распиновка

| GPIO | Назначение | Компонент |
|---|---|---|
| 4 | BTN1 | кнопка 1 → GND |
| 5 | BTN4 | кнопка 4 → GND |
| 13 | LED White | белый LED → резистор 220 Ω → GND |
| 14 | BTN3 | кнопка 3 → GND |
| 16 | LED Blue | синий LED → резистор 220 Ω → GND |
| 17 | LED Green | зелёный LED → резистор 220 Ω → GND |
| 18 | LED Yellow | жёлтый LED → резистор 220 Ω → GND |
| 19 | LED Red | красный LED → резистор 220 Ω → GND |
| 21 | I2C SDA (аппаратный) | OLED32 + BME280 |
| 22 | I2C SCL (аппаратный) | OLED32 + BME280 |
| 23 | BTN5 | кнопка 5 → GND |
| 25 | Soft I2C SDA | OLED64 |
| 26 | Soft I2C SCL | OLED64 |
| 27 | BTN2 | кнопка 2 → GND |
| 34 | LDR (ADC) | делитель напряжения |

**Питание:**

- ESP32 — USB 5 V
- OLED, BME280 — 3.3 V с ESP32

## I2C адреса

| Устройство | Адрес |
|---|---|
| OLED 128×64 | 0x3C |
| OLED 128×32 | 0x3C |
| BME280 | 0x76 (или 0x77) |

**Важно:** два OLED на разных шинах.

- Большой OLED — **софт-I2C** (GPIO 25/26)
- Малый OLED + BME280 — **аппаратный I2C** (GPIO 21/22)

Конфликта адресов нет.

## Схема (блоки)

```
                    ┌──────────────┐
                    │   ESP32      │
                    │   DevKit     │
                    └──┬─┬─┬─┬─┬───┘
                       │ │ │ │ │
           ┌───────────┘ │ │ │ └──────────┐
           │             │ │ │            │
        ┌──▼──┐   ┌──────▼─▼──────┐   ┌───▼────┐
        │OLED │   │  OLED 32 +    │   │ 5 LED  │
        │ 64  │   │  BME280       │   │+5 BTN  │
        │     │   │               │   │        │
        │25/26│   │  21/22        │   │ см.пины│
        └─────┘   └───────────────┘   └────────┘
```

## Кнопки

Подключение: **GPIO → кнопка → GND**

Внутренняя подтяжка ESP32 (`INPUT_PULLUP`) включена в коде.  
Нажатие = LOW.

## LED

Подключение: **GPIO → резистор 220 Ω → LED (анод) → LED (катод) → GND**

Активный уровень: HIGH.

## LDR

Делитель напряжения:

```
3.3 V ──── LDR ──── GPIO34 ──── 10 kΩ ──── GND
```

АЦП ESP32 читает 0–4095 (12 бит).

- Ярко → LDR мало → на пине много вольт → высокое значение
- Темно → LDR много → на пине мало → низкое значение

Калибровка в `firmware/sensors.cpp`:

```cpp
#define LDR_ADC_MIN   100
#define LDR_ADC_MAX   4000
```

Подстрой под свои условия.
